# Edge Add-ons Store Listing

## Extension Name
Mermaid Diagram Previewer

## Short Description (132 chars max)
Renders Mermaid diagrams on any web page. Supports all 23 diagram types with live preview, themes, zoom, and one-click copy.

## Detailed Description

Mermaid Diagram Previewer automatically detects and renders Mermaid code blocks on any web page — GitHub, GitLab, Azure DevOps, Confluence, MkDocs, Docusaurus, and more.

**All 23 Mermaid Diagram Types Supported:**
Flowchart, Sequence Diagram, Class Diagram, State Diagram, ER Diagram, Gantt Chart, Pie Chart, Mindmap, Timeline, Git Graph, Quadrant Chart, Requirement Diagram, C4 Diagram, Sankey Diagram, XY Chart, Block Diagram, Packet Diagram, Kanban, Architecture Diagram, Radar Chart, Treemap, User Journey, and ZenUML.

**Key Features:**

- Auto-Detection: Instantly finds and renders Mermaid code blocks in Markdown files, READMEs, wikis, and documentation pages.
- 4 Themes: Switch between Default, Dark, Forest, and Neutral to match your preference.
- Click to Zoom: Click any rendered diagram for a fullscreen view with scroll-wheel zoom.
- One-Click Copy: Copy the rendered SVG or the original Mermaid source to your clipboard.
- Toggle Source: Easily switch between the rendered diagram and the original source code.
- Built-in Editor: Open the popup to write, test, and preview Mermaid diagrams without leaving your browser.
- SPA Support: Works seamlessly with single-page applications — diagrams render correctly as you navigate between pages on GitHub, GitLab, and other SPAs.
- 23 Templates: Quick-start templates for every diagram type in the popup editor.
- Lightweight: Only loads the rendering engine when Mermaid blocks are detected on the page.

**Works On:**
- GitHub (repositories, PRs, issues, wikis, gists)
- GitLab (repositories, merge requests, wikis)
- Azure DevOps (repos, wikis)
- Confluence / Atlassian
- Bitbucket
- MkDocs, Docusaurus, Hugo, Jekyll
- Any site with Mermaid code blocks in Markdown

**Privacy:**
This extension does not collect, store, or transmit any user data. All rendering happens locally in your browser.
